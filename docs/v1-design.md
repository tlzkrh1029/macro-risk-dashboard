# 미국증시·크립토용 매크로 리스크 모니터링 체계

작성 기준일: 2026년 8월 19일

> 이 문서는 지표 해석 프레임에 관한 정리이며 투자 자문이 아닙니다.
> 임계값은 참고용 기준선이고, 실제 판단은 본인 상황에 맞춰 하셔야 합니다.

---

## 설계 원칙

이 대시보드는 **네 가지 원칙** 위에 세워져 있습니다.

1. **합산 점수를 만들지 않는다.** 지표들은 서로 상관관계가 높아서 합산하면 중복 계산됩니다. 대신 각각을 백분위로 표시하고, 세 줄을 나란히 읽습니다.
2. **레벨이 아니라 변화 속도를 본다.** 시장은 높은 레벨에 적응합니다. 깨지는 건 빠른 이동 때문입니다.
3. **진단과 경보를 분리한다.** "왜 오르는가"(느린 질문)와 "지금 깨지고 있는가"(빠른 질문)는 다른 지표, 다른 주기가 필요합니다.
4. **타이밍 신호가 아니라 사이징 신호로 쓴다.** 이 지표들 중 어느 것도 "언제 팔아라"를 말해주지 않습니다. "얼마나 실어도 되는가"를 말해줍니다.

## 계층 1 — 진단 (주 1회, 주말)

**묻는 질문: 금리 상승의 원인이 무엇인가?**

이 층은 매일 볼 필요가 없습니다. 성격은 주 단위로 바뀌지 않습니다.

| 지표 | 소스 | 무엇을 말하는가 |
|---|---|---|
| `DGS10` | FRED | 10년 명목금리 (기준값) |
| `DFII10` | FRED | 10년 실질금리 = 위험자산의 기회비용 |
| `T10YIE` | FRED | 브레이크이븐 = 시장의 10년 기대 인플레 |
| `THREEFYTP10` | FRED | ACM 10년 기간프리미엄 = 재정·공급 우려의 직접 측정 |
| `T10Y2Y` | FRED | 커브 기울기 (구조 확인용) |

### 판정표

`DGS10 = DFII10 + T10YIE` 이므로, 명목금리가 오를 때 **어느 쪽이 올랐는지**만 보면 됩니다.

| 실질금리 | 브레이크이븐 | 기간프리미엄 | 진단 | 위험자산 함의 |
|---|---|---|---|---|
| ↑ | → | ↑ | **재정·공급 주도** | 크립토에 최악. BTC 인플레 헤지 서사 불성립 |
| ↑ | → | → | 실질 성장 기대 상승 | 훨씬 덜 나쁨. 주식엔 오히려 우호적일 수 있음 |
| → | ↑ | → | 인플레 쇼크 | 주식 나쁨, BTC는 헤지 서사 작동 여지 |
| ↑ | ↑ | ↑ | 스태그플레이션 우려 | 전 자산군 악재 |
| ↓ | ↑ | ↓ | 완화 + 리플레이션 | **최상**. 2020~21년 구간 |
| ↓ | ↓ | → | 성장 둔화 / 침체 우려 | 국채는 좋고 주식·크립토는 나쁨 |

### 현재 판정 (2026년 8월)

- 브레이크이븐: 2024~2026년 내내 2.0~2.6% 박스, 4월 2.40%
- 실질금리: 4월 1.93% → 명목 4.7%, 브레이크이븐 2.3~2.4% 역산 시 현재 약 2.3~2.4%
- **판정: 실질금리 주도. 인플레 기대는 앵커돼 있음.**
- 확정 확인 필요: `THREEFYTP10`이 같이 오르고 있는가 → 그렇다면 재정·공급 주도 확정

**기록 방법:** 매주 일요일에 네 숫자를 적고, 전주 대비 변화를 bp로 기록. 4주 누적 변화가 판정보다 중요.

## 계층 2 — 경보 (매일, 5분)

**묻는 질문: 완충장치가 얼마나 두꺼운가?**

| 지표 | 소스 | 성격 |
|---|---|---|
| **HY OAS** (`BAMLH0A0HYM2`) | FRED (T+1) | 신용 스트레스의 가장 깨끗한 측정. 국채금리 영향 제거됨 |
| **HYG / LQD** | 증권사·트레이딩뷰 | 실시간 방향 감지. 단 금리 급변 시 오염됨 |
| **MOVE** | ICE BofA | 채권 변동성 = 보험 가격 = 레버리지 상태 |
| **VCLT / TLT** | 실시간 | 회사채 스프레드의 듀레이션 매칭 프록시 |
| `^TYX` / `^TNX` | Cboe | 장기·중기 금리 레벨 |

### 백분위로 읽기 (합산 금지)

각 지표를 **지난 3년 백분위**로 표시합니다. 지금 화면은 대략 이렇습니다.

```
30Y 금리       ▓▓▓▓▓▓▓▓▓▓ 99%tile   ← 19년 최고
HY OAS          ▓                  3%tile   ← 최저 십분위 (271~281bp)
MOVE            ▓▓                10%tile   ← 70대, 역사 평균 ~103
```

**이 세 줄의 조합이 핵심입니다.** 금리는 극단적으로 높은데 신용과 변동성은 극단적으로 잠잠하다 = 나쁜 소식이 가격에 안 들어가 있고, 아무도 헤지를 안 사놨고, 레버리지는 최대로 실려 있다.

### 완충 두께 판정 케이스

| 케이스 | HY OAS | MOVE | 상관관계 | 완충 | 예시 |
|---|---|---|---|---|---|
| **A. 정석적으로 두꺼움** | 400~500bp | 90~110 | 음(-) | 두꺼움 | 2019년 중반 |
| **B. 충격 직후** | 700bp+ | 150+ | — | 역설적으로 두꺼움 | 2020.4, 2022.10 |
| **C. 현재** | 270bp | 75 | 양(+) | **얇음** | 2026.8 |
| **D. 전형적 스트레스** | 확대 중 | 상승 중 | 양(+) | 붕괴 중 | 2022 전반 |

완충 두께 = ① 이미 가격에 반영된 악재의 양 + ② 정책 여력 + ③ 작동하는 헤지 자산 + ④ 레버리지 수준의 역수

### 경보 임계값

**레벨 기준 (참고용)**

| 신호 | 의미 |
|---|---|
| HY OAS > 350bp | 안일함 해소 시작. 관심 단계 |
| HY OAS > 450bp | 장기 중앙값 복귀. 주의 단계 |
| HY OAS > 600bp | 명확한 스트레스 |
| MOVE > 100 | 평균 복귀. 헤지 수요 발생 중 |
| MOVE > 126 | 역사적으로 S&P 500 유의미한 하락과 겹침 |

**변화 속도 기준 (이쪽이 더 중요)**

| 신호 | 의미 |
|---|---|
| HY OAS 주간 +30bp 이상 | 레벨과 무관하게 주의 |
| HY OAS 주간 +50bp 이상 | 강한 경보 |
| MOVE 주간 +20% 이상 | 헤지 수요 급증 = 레버리지 강제 축소 임박 |
| `^TYX` 주간 +25bp 이상 | 질서 있는 재가격이 아닐 가능성 |

**복합 경보 (이게 진짜 신호)**

```
🚨 HY OAS 확대 + MOVE 상승 + TLT 하락 + DXY 상승
   → 채권시장 스트레스가 위험자산으로 전이 중
   → 포지션 축소 검토 구간
```

```
✅ HY OAS 축소 + MOVE 하락 + TLT 상승 + DXY 하락
   → 금융여건 완화. 위험자산 우호적
```

**주의:** 계층 2는 **타이밍 신호가 아닙니다.** 타이트한 캐리 레짐은 몇 분기씩 지속될 수 있습니다. "얇다"는 건 "지금 떨어진다"가 아니라 "떨어질 때 깊고 빠르다"이므로, 포지션 크기와 헤지 비용 판단에 씁니다.

## 계층 3 — 실행 (주 1회 + 분기 실적 시즌)

**묻는 질문: 주식시장이 AI 조달비용을 가격에 넣기 시작했는가?**

이 층이 가장 중요하면서 가장 손이 많이 갑니다. 단일 티커가 없습니다.

### 3-A. 하이퍼스케일러 스프레드 추적 (주 1회, FINRA)

**설정 (최초 1회)**
1. finra.org/finra-data/fixed-income/bond 접속
2. 아래 발행사별로 만기 2033~2036년 부근 채권 **1개씩** 선정, CUSIP 기록
   - Oracle (BBB, 레버리지 최고) — 핵심
   - Microsoft (AAA급) — 기준선
   - Meta 또는 Alphabet (AA) — 중간
3. Bond Watchlist에 저장

**주간 루틴 (5분)**
1. 각 채권의 최근 체결 수익률 기록
2. 같은 날 `DGS10`(FRED) 값을 뺀다 → 스프레드
3. 아래 표에 기록

| 주차 | ORCL 스프레드 | MSFT 스프레드 | **격차** | 나스닥 주간 |
|---|---|---|---|---|
| | | | | |

**핵심은 "격차" 열입니다.** 오라클과 마이크로소프트의 스프레드 차이가 벌어지는 속도 = 시장이 AI 레버리지 리스크를 차등화하는 속도.

무료 실시간 소스가 없으므로 간접 추적:

참고 레벨: 2025년 중반 ~40bp → 2026년 7월 말 180~215bp (기록적 확대)

### 3-C. 괴리 판정

| 하이퍼스케일러 스프레드 | 나스닥 | 판정 |
|---|---|---|
| 확대 | 상승 | **⚠️ 진짜 괴리.** 채권시장은 넣고 주식은 안 넣음 |
| 확대 | 하락 | 정상적 전이. 이미 반영 중 |
| 축소 | 상승 | 건강한 상승 |
| 축소 | 하락 | 크레딧 외 요인(매크로·정책) |

첫 번째 행이 나타나면, "Nasdaq ↑ + TLT ↓↓"보다 훨씬 날카로운 경고입니다.

### 3-D. 분기 실적 체크리스트

실적 시즌마다 하이퍼스케일러 4~5개에 대해 확인:

- [ ] **캐펙스 가이던스** — 또 상향됐는가? (상향 = 자금조달 갭 확대)
- [ ] **잉여현금흐름** — 캐펙스가 FCF를 넘어섰는가? *이 교차점이 구조적 분기점*
- [ ] **구매 약정 / 부외 항목** (10-Q 주석) — 급증했는가?
- [ ] **감가상각 내용연수** — 변경됐는가? *GPU 수명 연장 = 이익의 인위적 개선*
- [ ] **신규 채권 발행 스프레드** — 기존 채권 대비 얼마나 넓게 발행됐는가?

마지막 항목의 판단 기준: 신규 발행이 기존 채권 스프레드보다 크게 넓으면 "억지로 팔았다"는 뜻. 참고로 하이퍼스케일러 채권 응찰배율은 2026년 2월 약 5배 → 7월 2배 미만으로 하락했습니다.

## 크립토 전용 보조 계층

BTC는 현금흐름이 없어서 가치평가가 순전히 기회비용에 달려 있습니다. 따라서 계층 1의 `DFII10`이 크립토에겐 가장 중요한 단일 지표입니다.

| 추가 지표 | 이유 |
|---|---|
| `DFII10` (계층 1에서 이미 봄) | 현금흐름 없는 자산의 기회비용. 역상관 |
| DXY | 달러 강세 = 글로벌 유동성 축소 |
| 금(GLD) 대비 BTC 상대강도 | 두 자산 모두 현금흐름 없음. 갈라지면 BTC 고유 요인 |

**크립토 최악 조합:** 실질금리 ↑ + 기간프리미엄 ↑ + DXY ↑
→ 화폐 훼손 서사가 작동해야 할 국면인데 기회비용이 더 강하게 눌러버림. 현재가 여기에 가깝습니다.

**크립토 최상 조합:** 실질금리 ↓ + 브레이크이븐 ↑ + DXY ↓

## 이 대시보드가 하지 않는 것

솔직하게 적어둡니다.

- **매도 시점을 알려주지 않습니다.** 완충이 얇은 상태는 몇 분기 지속될 수 있고, 그동안 시장은 오를 수 있습니다.
- **AI 캐펙스의 성패를 예측하지 않습니다.** 자금조달 조건이 나빠지는 속도만 보여줍니다.
- **상관관계 레짐 변화를 자동으로 잡지 못합니다.** 인플레 레짐에서 성장 레짐으로 바뀌면 계층 2의 복합 경보 규칙을 다시 해석해야 합니다.
- **개별 종목 판단을 대신하지 않습니다.**

가장 정직한 사용법: 이 대시보드는 "지금 얼마나 실어도 되는가"에 대한 답이지 "지금 사야 하는가 팔아야 하는가"에 대한 답이 아닙니다.
