# v2 검토에 쓴 실증 스크립트

`docs/review-v2-2026-10-14.md`의 근거가 된 스크립트와 원자료입니다.

| 파일 | 내용 |
|---|---|
| `results.json` | 관점별 비판 5건, 검증 판정, 실증 2건과 각 감사 결과, 종합 판정 전문 |
| `backtest_v2_sizing.py` | v2 사이징 규칙과 단순 기준선(매수 후 보유, 200일선, 15% 변동성 목표, 경보만 사용) 백테스트 |
| `alarm_robustness.py` | 복합 경보 A·B형의 일별 재계산, 표본 밖 검증, 민감도, 부트스트랩, 단일 지표 경보와의 비교 |

주의할 점:

- 두 스크립트는 감사 **이전** 버전입니다. 감사에서 찾은 오류(백테스트의 결측 상태 처리, 금리 데이터 공표 지연 미반영, 경보 유의성 검정의 군집 무시 등)와 수정된 숫자는 `results.json`의 `empirical[].audit`에 있고, 보고서는 수정된 숫자를 씁니다.
- 스크립트 안의 `SCRATCH` 경로는 검토 환경의 임시 디렉터리를 가리킵니다. 다시 실행하려면 이 경로를 바꾸고, 먼저 `python analysis/verify_v1.py`로 `analysis/.cache/`를 채워야 합니다.
